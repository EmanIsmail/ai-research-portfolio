# Arabic CRM AI System

## Overview

An enterprise AI system for Arabic CRM ticket classification, intelligent routing, and analytics using machine learning and large language models (LLMs).

The project focuses on improving customer support intelligence through automated understanding of Arabic support tickets and complaint analysis.

---

## Problem Statement

Enterprise CRM systems receive large volumes of Arabic customer tickets that require:
- Manual classification
- Intelligent routing
- Pain-point identification
- Customer issue analytics

Traditional workflows are time-consuming and difficult to scale, especially with Arabic text complexity and domain-specific terminology.

---

## Objectives

- Automate Arabic ticket classification
- Compare classical ML methods against LLM-based approaches
- Explore Retrieval-Augmented Generation (RAG)
- Improve enterprise CRM analytics
- Support intelligent customer issue understanding

---

## Dataset Characteristics

The dataset includes:
- Arabic CRM tickets
- Customer complaints
- Tax and service-related categories
- Pain-point labels
- Multi-class classification targets

### Challenges
- Arabic language complexity
- Domain-specific terminology
- Imbalanced classes
- Label overlap
- Long-text understanding
