## Research Overview

My master's research focused on developing computational and machine learning approaches for drug repositioning and biomedical interaction prediction.

The research introduced an integrated framework to model relationships among:
- Drugs
- Biological Targets
- Diseases

using machine learning and pattern recognition techniques. :contentReference[oaicite:0]{index=0}

---

## Research Objectives

The thesis aimed to:
- Integrate drug, target, and disease biological spaces into a unified framework
- Model Drug-Target Interaction (DTI)
- Model Target-Disease Interaction (TDI)
- Improve prediction quality using semi-supervised learning approaches
- Explore feature-based representations instead of traditional similarity/network-only methods
- Accelerate drug discovery through computational intelligence approaches
